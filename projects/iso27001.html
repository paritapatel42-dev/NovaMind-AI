ISO/IEC 27001:2022 Implementation

A complete Information Security Management System (ISMS) implementation created for a fictional e-commerce organization, following ISO/IEC 27001:2022 best practices.

Company

NovaCart Solutions

Industry

E-Commerce

Duration

12 Weeks

Framework

ISO/IEC 27001:2022
PROJECT OVERVIEW

Executive Summary

NovaCart Solutions is a fictional mid-sized e-commerce company operating across India and the UAE. As part of this portfolio project, an Information Security Management System (ISMS) was designed and documented following the requirements of ISO/IEC 27001:2022.

The objective of this implementation was to establish a structured approach to information security by identifying organizational assets, assessing business risks, selecting appropriate Annex A controls and developing essential ISMS documentation.

This project demonstrates practical Governance, Risk and Compliance (GRC) skills including risk assessment, policy development, asset management, documentation and ISO/IEC 27001 implementation within a realistic business environment.

Project Objectives

  • ✔ Establish the ISMS Scope
  • ✔ Identify Information Assets
  • ✔ Perform Risk Assessment
  • ✔ Select Annex A Controls
  • ✔ Create ISMS Documentation
  • ✔ Develop Risk Treatment Plan
